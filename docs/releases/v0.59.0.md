## 🕵️ Trilha de auditoria da plataforma — o tema desta versão
- **Ações de admin da organização deixam rasto**: toda ação administrativa autorizada emite evento de auditoria, em simetria com o back-office (#1571).
- **Auditoria por construção**: o tipo que representa "autorizado" só nasce com o auditor presente — esquecer de auditar deixou de compilar (#1583).
- **Sondagem de config alheia registrada**: tentar ler a configuração de outro usuário (caminho negado) agora gera evento de auditoria — enumeração deixa rasto (#1589).

## 🔧 Melhorias
- **Config do usuário servida na borda**: `GET /me/config` entrega a allowlist real de preferências pra plataforma web (#1505).
- **Org suspensa sem gaguejo**: a tela da plataforma trata organização suspensa de forma estável, sem re-render em loop (#1544).
- **Remote**: primeiro comando do pipe SYSTEM (Ping) com autorização por comando — porteiro default-deny em ação (#1457).

## 📚 Sob o capô
- Contrato do Register v2 do Remote saiu de comentário para documento versionado, e a doc ficou livre de byte NUL que quebrava ferramentas de busca (#1129).
- Semente de dev pra org suspensa + sessão, habilitando o teste composto de QA (#1544).
